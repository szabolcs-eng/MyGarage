# MyGarage

MyGarage is a mobile application developed using **.NET MAUI** and **C#**. Its purpose is to help vehicle owners manage their vehicles and keep track of their maintenance history.

## Features

- Vehicle management (CRUD operations)
- Service history tracking
- Local SQLite database
- Invoice and service-related photo capture
- GPS-based service location recording
- Map-based location visualization

## Technologies

- C#
- .NET 10
- .NET MAUI
- XAML
- SQLite
- MVVM Architecture

## Project Structure

- `src/` – Application source code
- `docs/` – Project documentation and images
- `tests/` – Tests
